# Archive

Future home for superseded policies, frozen benchmark revisions and retired
experiment trees.

Good candidates, once their references are checked:

- `benchmark/_superseded_inventory/`
- old policy bundles that are fully represented in `benchmark/models/`
- archive-only revisions that no current report reruns

Archives are immutable: keep the original manifest, hashes and report links.
Do not rewrite an archived receipt to make it match a newer tree.
